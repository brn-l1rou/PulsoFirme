# Pulso Firme

Aplicativo de controle de Glicemia.

## Objetivo

Desenvolver um aplicativo móvel para auxiliar no controle da glicemia de um 
paciente com diabetes, permitindo o registro estruturado das medições, visualização 
de histórico, emissão de alertas e compartilhamento das informações entre 
cuidadores. A criação de soluções baseadas em smartphone para gestão de doenças 
crônicas, como o diabetes, é uma estratégia reconhecida por aumentar o autocuidado 
e a adesão ao tratamento (DOUPIS et al., 2020; SILVA et al., 2020).
